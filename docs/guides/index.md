A guide walks through one ceremony or one transition, step by step, with the result of each step and a drill on test keys.

| Guide | When |
|---|---|
| [Adopting the roots](/guides/root-adoption/) | Once, at the start: the real roots on two cards, and the drill that comes first. |
| [A lost root card](/guides/lost-root-card/) | A root card is lost, stolen or compromised. |

One guide per transition between key stores follows with the tools ([issue #19](https://github.com/truvity/ritueel/issues/19)).
