A guide walks through one procedure step by step, with the result of each step and a drill on test keys. The guides say *how*; the pages under [Learn](/learn/) say *why* and *when*, so read the matching Learn page first if a step is not clear.

| Guide | When | Learn first |
|---|---|---|
| [Adopting the roots](/guides/root-adoption/) | Once, at the start: the real roots on two cards, and the drill that comes first. | [The life of a root](/learn/life-of-a-root/) |
| [A lost root card](/guides/lost-root-card/) | A root card is lost, stolen or compromised. | [Layered trust](/learn/layered-trust/) |

More guides follow, one for each ritual and each transition between key stores ([issue #19](https://github.com/truvity/ritueel/issues/19)). The drills are tracked in [issue #20](https://github.com/truvity/ritueel/issues/20).
