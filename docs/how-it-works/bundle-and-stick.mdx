## The bundle

A bundle holds everything ritueel knows about one trust domain: plain files, and never a private key in clear ([the layout](/reference/bundle/#the-layout)). You write two places; ritueel writes the rest.

<Figure name="bundle-folder">
  A bundle is one directory of plain files for one trust domain. Its history of ceremonies (see the [glossary](/glossary/)) is never changed afterwards.
</Figure>

Two parts of the bundle are drawn without a directory name because their names are being changed.

## The USB stick

A root on cards or in a key file runs on the offline system, and the plan is carried there on a stick ([record 0005](../decisions/0005-a-ceremony-and-where-it-runs.md)). A cloud root needs no stick: it runs on your workstation.

The stick holds vanilla AirgapOS and one extra partition for ritueel: several versions of ritueel, several bundles and the encrypted key files. When you prepare a plan online, ritueel refreshes its copy on the stick and the plan records its digest, so the run uses the version that made the plan.

<Figure name="usb-stick">
  Key files sit beside the bundles, not inside: a bundle is made to be copied and shared; a key file is the root itself, even though it is encrypted.
</Figure>

<Proposed>
  The directory names on the partition, and the plan member that records the digest, are proposals, not yet in a record; the label and the file system are open. That AirgapOS boots from such a stick and uses the extra partition is still to be proven on hardware.
</Proposed>
