# ritueel

ritueel keeps the roots of trust: the X.509 CA roots and OpenPGP primary keys that other keys depend on. It creates them, vouches for the next one, overlaps the old and the new, supersedes, revokes, and runs the ceremonies where a person is present. It is open source (MIT) and a teaching product: the site at [ritueel.id](https://ritueel.id) explains the model before the tools do it for you.

Status: **design phase.** There is no release yet. The first docs, the scope decision and the roadmap are on their way in pull requests; the backlog is in the [issues](https://github.com/truvity/ritueel/issues).

ritueel is a separate product from [sluis](https://sluis.id). The two do not depend on each other and exchange standard formats only.
